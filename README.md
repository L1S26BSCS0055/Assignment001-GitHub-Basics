Sum of First 50 Natural Numbers
Program Description

This C++ program calculates the sum of the first 50 natural numbers using two methods.

Loop method: Uses a for loop to add the numbers from 1 to 50.
Formula method: Uses the formula n(n+1)/2 to verify the result.

Both methods produce the same answer: 1275.

Sample Output
Sum of first 50 natural numbers (loop): 1275
Sum using formula n(n+1)/2: 1275
